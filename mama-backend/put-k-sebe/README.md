# Подключение вечерних напоминаний

Сервис подготовлен, но не развернут. Текущие приложения сайта и бот для мамы не меняются.

1. Подключить отдельный Cloudflare Worker с `main = worker.mjs` к маршруту `yuliastoyanova.com/put-k-sebe/api/*`.
2. Создать отдельную D1, выполнить `schema.sql`, добавить binding `PUT_K_SEBE_DB`.
3. Сохранить секрет `PUT_K_SEBE_BOT_TOKEN` через защищенное хранилище Cloudflare. Не помещать его в файлы или клиентскую конфигурацию.
4. Настроить cron `* * * * *` в этом отдельном Worker.
5. В BotFather настроить Mini App марафона на `https://yuliastoyanova.com/put-k-sebe/`. Пользователь должен запустить этого бота или дать ему разрешение на сообщения.
6. После проверки сервиса указать в `config.js` реальный `marathonBotUsername` и `reminderApiUrl: '/put-k-sebe/api/reminder'`.

Согласие по умолчанию выключено. Сервер проверяет подпись Telegram initData, время, часовой пояс и согласие; сообщение открывает `#evening/3`, `#evening/4` или `#evening/5`. Уникальная запись на пользователя и местную дату предотвращает повторную отправку. Переходы не зависят от подключения уведомлений.

В текущей сборке endpoint пуст, отправка сообщений не производится. Сервис не хранит ответы участника, только настройки напоминания. Прогресс остается в браузере, с экспортом и импортом резервной копии.
