# ДЛЯ СЕБЯ — 40 карточек заботы о себе

Самостоятельное mobile-first приложение в директории `care/`. Запускается как статический сайт; для PWA и service worker нужен HTTPS или localhost.

## Содержимое

- `data/cards.json` — перенесенные из исходной таблицы тексты и нумерация карточек.
- `assets/cards/optimized/` — оптимизированные WebP для просмотра карточек.
- `assets/cards/thumbs/` — облегченные WebP-превью каталога.
- `../formyself/` — предоставленные оригиналы, оставлены без изменений.
- `manifest.webmanifest`, `sw.js`, `icons/` — базовая установка PWA и кэширование оболочки/уже просмотренных карточек.

Все выборы, история, избранное и личные заметки сохраняются в localStorage текущего браузера. Данные пользователя не отправляются на сервер.

Для размещения на `yuliastoyanova.com/care/` достаточно опубликовать содержимое этой папки в соответствующий путь статического хостинга. Текущая папка проекта не содержит deployment-конфигурации сайта, поэтому автоматическая публикация и подтверждение доступности URL здесь невозможны.

Analytics events use the local `dlya:analytics` CustomEvent abstraction. No third-party analytics provider is connected.
