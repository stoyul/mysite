# «Путь к себе»: самостоятельное приложение

Вводный урок и Дни 1–5 открываются в `https://yuliastoyanova.com/put-k-sebe/`. Главная страница больше не загружает приложение через iframe ChatGPT. Встроенные iframe используются только для YouTube.

Приложение сохраняет единое состояние в localStorage с резервной копией: намерение, желания и категории, планы, состояния, ресурсы, благодарность, цели, вечерние ответы и финальную рефлексию. Перезапуск этого же браузера или WebView сохраняет записи. Между устройствами автоматической синхронизации нет. В настройках доступны экспорт JSON и объединяющий импорт, включая экспорт предыдущего приложения.

Конфигурация находится в `../config.js`. Единственные пустые внешние ссылки: `consultationUrl`, `supernovaUrl`. Бот помощника уже задан: `https://t.me/IntentionCrystal7D_bot`. Все шесть основных YouTube URL заданы в `src/program.js`, включая `day3.videoUrl`.

Сборка: установить Vite 8.0.13 через npm, выполнить `npm run build`. Исходники собираются сначала в `dist/`, затем только новые файлы копируются в родительскую папку `put-k-sebe/`. Старые файлы не удаляются. Тесты: `npm test`. Не запускать публикацию до обязательной проверки полного интерфейсного сценария.

Telegram: safe areas, адаптивная нижняя навигация, fullscreen-safe CSS, `playsinline` для YouTube, Telegram BackButton и маршруты `#evening/3`, `#evening/4`, `#evening/5`. `startapp=evening_3` и аналогичные параметры открывают соответствующую вечернюю практику, если бот и Mini App зарегистрированы. Настройка напоминаний выключена до подключения отдельного Worker. Код сервиса находится в `mama-backend/put-k-sebe/`, который исключен из раздачи статических ассетов существующим `.assetsignore`.

Не проверено в реальном браузере, Safari/Chrome на телефонах и Telegram Mini App: инструмент браузера отказал из-за недоступной проверки административной политики. До устранения ограничения эта ветка остается черновиком. Финальная публикация на production не выполнялась.
