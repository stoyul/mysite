## Требует данных или настройки автора

- consultationUrl: реальный URL записи на консультацию.
- supernovaUrl: URL программы «Рождение сверхновой», если она уже открыта.
- Реальная аудиозапись медитации «Создание намерения». В доступных материалах ее нет. Фиктивное аудио не создано.
- Бот самого марафона: username, зарегистрированная Mini App и секрет токена в Cloudflare. IntentionCrystal7D используется только как помощник для формулировки намерения.
- Для Telegram-напоминаний нужен отдельный Worker и D1. Их исходники подготовлены; отправка не активирована. Существующий бот /for-mama/ не изменен.
- Автоматическая синхронизация между устройствами не подключена. На том же устройстве действует localStorage; для переноса доступны экспорт и импорт.
- Старые серверные записи ChatGPT не копировались автоматически. Они остаются в прежнем приложении; новый импорт понимает его JSON-экспорт.

## Обязательная проверка перед merge/deploy

Главная → Как проходит → Вводный → сохранить намерение → День 1, добавить три желания и категорию → День 2, создать план, выполнить действие, записать состояние → завершить день → переход к Дню 3 → ресурсы и благодарность → День 4, выбрать существующее желание, создать цель → проверить Мои жизненные цели → День 5 и рефлексия → финал. Повторить перезагрузку и закрытие/открытие браузера. Проверить iPhone/Safari, Android/Chrome и настоящий Telegram Mini App с клавиатурой и YouTube.

После merge main Cloudflare получает новую версию из GitHub. Для существующего /put-k-sebe/ может требоваться сброс кэша Cloudflare. Проверить метатег marathon-version=3 и загруженные локальные ассеты на production, затем пройти маршрут снова.
