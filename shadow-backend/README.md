# Архетипы Тени и Силы

Адрес: https://yuliastoyanova.com/shadow-transformation/

Сохранено существующее приложение из версии 3 Sites: 60 архетипов, описания, метакоды, рекомендации, переворот, кристаллы, коллекция и ключ сохранения shadow-strength-paths-v1. Исходные иллюстрации переведены в WebP для мобильной загрузки; оригинальные JPEG сохранены в папке материалов. Четные номера — Тень, нечетные — Сила.

Вход проверяет Cloudflare Worker, PBKDF2 SHA-256 (100000 итераций). Серверная конфигурация находится в code-config.mjs; код не хранится в открытом виде и не передается в клиентских скриптах. Сессии живут 30 дней, токены случайные, в D1 сохраняются только их хеши. Cookie: HttpOnly, Secure, SameSite=Strict, ограничена путем приложения. Изменение хеша отзывает старые сессии. Кнопка сброса отзывает текущую сессию, сохраняя результаты. Ограничение: 10 попыток на IP за 15 минут. Используются отдельные таблицы shadow_sessions и shadow_attempts в существующей D1, остальные таблицы не меняются.

## Изменить код

Запустите node shadow-backend/change-code.mjs в терминале. Введите новое слово в скрытом поле. Скрипт обновит только code-config.mjs. Опубликуйте этот файл через main существующего репозитория; Cloudflare применит изменение. Основной интерфейс менять не требуется. При использовании переменных SHADOW_CODE_HASH и SHADOW_CODE_SALT обновляйте обе, согласованно с 100000 итераций.

## Консультация

Приглашение находится над самостоятельной практикой. Сообщение содержит приложение, название Тени и Силы. Ссылка https://t.me/Stoyu?text=... соответствует официальной документации Telegram https://core.telegram.org/api/links#public-username-links. Дополнительно доступно копирование текста и открытие чата. Пользователь самостоятельно отправляет сообщение.

## Хранение результатов

Результаты сохраняются в текущем браузере. Перенос с прежнего домена Sites на основной домен автоматически не переносит localStorage. Старый опубликованный проект не изменен и остается доступным для просмотра прежних результатов.

## Проверки

Локально проверены неверный/верный код, сессия после обновления, сброс, защита 120 сторон карт, ограничение попыток и отсутствие изменений маршрутов других продуктов. В браузере проверены переворот, описание, практика, осознание, сохранение, коллекция после обновления, сообщение и буфер обмена. Мобильные ширины 320 и 375 px без горизонтальной прокрутки. Проверка физического смартфона не выполнялась.
