# LUNA · Ваш личный ритм

Основной адрес: https://yuliastoyanova.com/moon/

Приложение размещается отдельной папкой `moon/` в `stoyul/mysite`, автоматически публикуется существующим Cloudflare Workers Static Assets. Папка `dist/` — готовый сайт; никакой сборки для размещения не требуется.

## Что работает

- Главный экран с единой рекомендацией по отмеченному циклу, выбранному центру, фазе Луны, сезону и записи об энергии.
- Геоцентрические астрономические расчёты Astronomy Engine 2.1.19: освещённость, фаза, тропический знак, ближайший переход, новолуние, полнолуние, глобальные затмения. День Луны — целые сутки после новолуния, не традиционные сутки по местным восходам. Видимость затмения по местоположению не рассчитывается.
- Календарь с просмотром дней, переходом между месяцами, отметками дневника и прогнозами.
- История начала циклов, настройки длины, приблизительная оценка овуляции и фертильного окна. Предполагаемые новые циклы не записываются как реальные.
- Все 11 авторских карточек центров, выбор и история; инструкции к маятнику, самонаблюдению и мышечному тесту с иллюстрацией.
- Дневник: настроение, энергия, сон, самочувствие, симптомы, эмоции, благодарность и заметки. Средние и график энергии, длина отмеченных циклов, наблюдения по центрам.
- Расширяемый каталог, поиск, фильтры, локальный редактор, импорт/экспорт JSON.
- Устанавливаемая PWA с отдельным service worker в пределах `/moon/`, офлайн-оболочка и карточки.
- Telegram WebApp SDK, расширение экрана и BackButton. Подключение к боту владелица выполняет самостоятельно; нужен этот же URL в BotFather.
- Печать / сохранение PDF средствами браузера: выбранный день, 7 дней, 30 дней, дневник, история, ритуалы и карточки.
- Напоминания ICS для календаря телефона; тест системного уведомления при открытом приложении.
- Резервная копия личных записей с проверкой формата перед восстановлением.

## Хранение и редактирование

`dist/data/library.json` — публичный структурированный каталог версии 1. Запись имеет постоянный `id`, категорию `type`, заголовок, описание, поле `fields` (название → текст), источник, статус и тип материала. Новые поля отображаются автоматически. Редактор сохраняет изменения в браузере владельца; для общего обновления нужно экспортировать каталог и заменить файл в репозитории.

`data/knowledge.sqlite` — нормализованная внутренняя база: категории, материалы, поля, исходные документы, версия схемы. Пересоздание: `scripts/build_database.py`. Исходные документы и полные транскрипты остаются локально, не включаются в публичную папку сайта. `data/source-materials.json` содержит 8 извлечённых DOCX как данные, а не инструкции программе.

Личные записи хранятся на устройстве в `localStorage` под отдельным ключом `ys-luna-v1`. Это не облачная синхронизация. Настройки, дневник, история циклов и центров включены в резервную копию. На общем устройстве доступ к браузеру означает доступ к записям. Для отдельной серверной базы понадобятся учётные записи, правила доступа и миграция; нельзя подключать общую незащищённую таблицу с пользовательскими данными.

## Контент и незавершённые интеграции

Центры подключены из предоставленных карточек. Остальные разделы имеют стартовые записи и поля для дальнейшего заполнения, а не полную энциклопедию. Французский дневник и аудиомедитации в папке отсутствуют; их загрузка остаётся отдельным этапом. Не выдуманы аудиофайлы и авторские тексты.

Telegram-рассылка, серверные push при закрытом приложении и синхронизация между устройствами не включены. Service worker содержит обработчик будущих push, но отсутствуют push-подписки, VAPID-ключи и сервер доставки. Напоминания в этой версии выполняет импортированный календарь телефона.

Трактовки Луны, центров, минералов, чакр и ароматов — символические практики; они не представлены как медицинские данные или основание для покупок, договоров и иных важных решений. Источники ухода — AAD, физиологии цикла — NHS. Библиотека хранит атрибуцию каждого материала.

## Проверка

`tests/model.cjs`: астрономические расчёты за год, дата новолуния, переходы DST, цикл, целостность 11 изображений и уникальность ID. Проверены интерфейсные сценарии добавления цикла, дневника и центра; мобильная ширина 390 px без горизонтального переполнения. Пробные записи остаются только на локальном адресе проверки и не публикуются.
