# Сакральная геометрия — Sakura

Независимое статическое приложение в подпапке `/Sakura/` сайта `yuliastoyanova.com`. Оно публикуется из `stoyul/mysite`, ветка `main`, штатной раздачей Cloudflare Workers Static Assets. Все файлы приложения, данные, иллюстрации и метаданные находятся внутри этой папки. Базовые URL и канонический адрес настроены для `/Sakura/`; выбранный символ и категория открываются по URL-параметрам `?symbol=` и `?category=`.

Личные заметки и история используют только ключи `sakura.notes.v1` и `sakura.history.v1`. Service Worker в приложении не регистрируется; собственный кэш оно не создаёт.

## Источники и права на изображение

Изображение `images/met-jali-453261.jpg` — фотография предмета коллекции The Metropolitan Museum of Art, *Pierced Window Screen (Jali)*, object 1985.240.2. Метаданные музея отмечают предмет как Public Domain. Атрибуция, период, место и пояснение находятся в `education.json`; ссылка на музейную карточку: https://www.metmuseum.org/art/collection/search/453261.

Дополнительные научные и музейные ссылки хранятся рядом с образовательными текстами в `education.json`. Авторские поля 84 символов сохранены из исходной книги «Карточки геометрия.xlsx».
