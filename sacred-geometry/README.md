# Сакральная геометрия | Атлас символов

Самостоятельное статическое приложение, обновляющее данные атласа Sakura по адресу `/sacred-geometry/`. Репозиторий `stoyul/mysite`, публикационная ветка `main`. Другие приложения и прежняя версия `/Sakura/` сохранены. Сайт использует Cloudflare **Workers Static Assets**, а не Pages: `wrangler.toml` публикует корень репозитория. Приложение совместимо и с Pages без сборки, но перенос действующего сайта не требуется.

## Каталог и изменения версии 2

Исходные 84 записи сохранены. Основной каталог содержит 77 элементов в 12 категориях. Семь карточек «АРХЕТИП…» доступны отдельно через раздел авторских архетипов; их личные записи и избранное сохраняются. Переработаны 29 изображений. `audited-geometry.js` содержит проверенные проекции с выделенными гранями, скрытыми ребрами и сменой ракурса; `audited-education.js` отделяет выбранную модель от исторической атрибуции.

## Печатная колода

`#print` открывает выбор одной карточки, нескольких, категории или всех 77 элементов каталога. Предпросмотр, отдельный двухстраничный PDF, SVG обеих сторон, общий PDF и ZIP создаются в браузере. Макет один для предпросмотра и PDF; векторные пути передаются через svg2pdf.js, текст через встроенные TrueType-шрифты. Библиотеки и печатные шрифты загружаются только при открытии мастерской. Лицензии включены рядом с файлами.

MediaBox/BleedBox: 76 × 106 мм. TrimBox: 70 × 100 мм, вылеты 3 мм. Безопасное поле 4 мм от линии реза. Основной текст 10 pt, название 15 pt, минимальный 9 pt. Все 154 стороны проходят проверку расположения строк; уменьшение ниже 9 pt не используется. Метки реза переключаются отдельно. Пары страниц идут как лицо, оборот, без поворота. Для печати карточного формата: 100% без масштабирования, переворот по длинной стороне; перед тиражом необходим пробный экземпляр. Для больших листов требуется спуск полос.

Экспорт RGB, **не PDF/X**. Подходящий ICC-профиль типографии не предоставлен; готовый CMYK/PDF-X не заявляется. Золотой цвет является обычной печатной краской, а не фольгой. Настоящее тиснение требует отдельного технологического слоя. Растровых иллюстраций в колоде нет, поэтому ограничение 300 dpi к геометрии и тексту не применяется.

Раздел истории дополнен библиотекой: 8 книг и 4 научных/музейных материала. Академические исследования, исторические источники и современные эзотерические трактовки разделены.

## Данные и точность

`symbols.json`: все 84 строки, 13 исходных категорий и девять полей B:J сохранены **дословно**, включая пробелы, знаки и переносы строк. `source-table.json` содержит исходные значения, название листа и номер строки для сверки. Источник: «Карточки геометрия.xlsx», пользователь подтвердил идентичность версии с суффиксом (1).

`geometry.js` содержит явное построение для каждого имени. Универсальной резервной картинки нет. SVG создаются в интерфейсе из координат. Математические модели и авторские визуальные интерпретации подписаны отдельно. Орнаментальные янтры планет не выдаются за подтвержденную историческую реконструкцию. Для них требуется эталон конкретной традиции.

`education.js` отдельно хранит редакционные сведения и проверяемые источники. Отсутствующая историческая атрибуция явно отмечается. Авторские поля, включая трактовки энергии и диагностики, не используются как научные утверждения.

Шри-янтра: численное решение условий (i)-(iii) Alessandro Chiodo (2021), DOI 10.5802/crmath.163. Данные в `shri.js`. Невязка системы меньше 1e-9 в единицах радиуса. Независимый подсчет областей нечетного покрытия подтверждает 14+10+10+8+1=43. Декоративные лепестки и внешняя граница не являются реконструкцией конкретного артефакта. Аналитические кривые аппроксимированы SVG-полилиниями по формуле; их координаты остаются векторными.

## Личные данные

`storage.js` реализует заменяемый адаптер сохранения. Используется отдельный ключ `sacred-geometry.v1`. При первом открытии импортируются `sakura.notes.v1` и `sakura.history.v1` без удаления старых ключей. Избранное, две записи на символ, просмотренные карточки и последний раздел сохраняются в браузере. Измененные записи сохраняются при уходе из карточки, кроме кнопки ручного сохранения. Поддерживаются экспорт и объединяющий импорт JSON, проверка формата и обработка отказа localStorage.

Серверной синхронизации нет. Для дальнейшего подключения можно заменить адаптер с контрактом `save/note/toggle/visit/route/export/import`; потребуется сервер и проверка Telegram initData на сервере.

## Telegram

SDK подключен с `https://telegram.org/js/telegram-web-app.js`. Инициализация вызывает ready/expand, задает цвета, учитывает safeAreaInset и contentSafeAreaInset, реагирует на события размеров и связывает BackButton с возвратом в коллекцию. Приложение работает и без SDK в обычном браузере. Токены не используются в клиенте.

Настройка существующего бота: в @BotFather откройте `/mybots`, выберите нужного бота, затем Bot Settings → Menu Button и укажите `https://yuliastoyanova.com/sacred-geometry/`. Для основной Mini App используйте Configure Mini App и тот же URL. Не меняйте webhook других приложений. В этой задаче конкретный бот не был указан и его настройки не изменялись.

Фактический запуск внутри Telegram на iOS/Android требует подключенного бота и проверки на устройствах. Локальная проверка SDK с имитацией не заменяет такую проверку. Скачивание SVG через Blob работает в браузере; поведение сохранения файла зависит от версии Telegram WebView.

## Разработка и проверки

Сборка отсутствует. Запустите HTTP-сервер из корня репозитория и откройте `/sacred-geometry/`. Файлы используют относительные ссылки.

- `node tests/geometry.test.mjs`: число строк/категорий, буквальное совпадение каждого исходного поля, уникальность всех 84 SVG, симметрия решетки, отношения Весика Писцис, правильные многоугольники, равенство ребер многогранников, гиперкубы, золотое отношение, непрерывность дуг Фибоначчи, 22 связи Древа, условия пересечений Шри-янтры, сохранение и перенос старых заметок.
- `tests/browser.mjs`: поиск, избранное, заметки/перезагрузка, вкладки, масштаб/направляющие, построение/пауза, адаптация 390/1440 px, reduced motion. Задайте ATLAS_URL для сервера и CHROME_PATH для установленного Chrome.
- `tests/audit.test.mjs`: грани и ребра многогранников, формула Эйлера, замыкание тора, восемь сфер Яйца жизни, исправленный герметический граф, каталог/архив.
- `tests/revision-browser.mjs`: все ракурсы, крупные шрифты, библиотека, 154 печатных макета, отдельные SVG/PDF, ZIP и полный PDF колоды.
- `tests/verify-print.py`: реальный MediaBox/TrimBox/BleedBox всех страниц, наличие FontFile2, эффективный размер текста с учетом CTM не ниже 9 pt, отсутствие растровых изображений.
- `tests/verify-shri.py`: независимый расчет Шри-янтры и подсчет треугольных областей (numpy, scipy, shapely). Скрипт используется для верификации, не загружается приложением.

Для добавления символа добавьте строку данных и явное построение в `geometry.js`, затем редакционные сведения. Измените ожидаемое число в тестах и метаданных только при утвержденном расширении каталога.

## Публикация

Добавляются только файлы `sacred-geometry/` в существующий репозиторий. Конфигурация Worker и маршруты других приложений не изменяются. GitHub-коммит в main запускает существующий механизм публикации. После него требуется проверить публичный HTML и версии данных/скриптов; при старом содержимом очистить соответствующие URL в Cloudflare. Успешный коммит сам по себе не подтверждает публикацию.
