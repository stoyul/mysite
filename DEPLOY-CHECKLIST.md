# Чек-лист перед деплоем — yuliastoyanova.com (репозиторий stoyul/mysite)

Хостинг: статика из корня репозитория (Cloudflare Pages по `wrangler.toml` + `.nojekyll`).
Домены: **https://yuliastoyanova.com**, зеркала — `stoyul.github.io/mysite`, `mysite.pages.dev`.
Чистые URL: `/tochka-sily` → отдаёт файл `tochka-sily.html`; `/foo/` → `foo/index.html`.

Каждый деплой = `git commit` + `git push origin main`. Хост пересобирается автоматически.

---

## 1. ССЫЛКИ ведут на нужные страницы

При добавлении/переименовании любой страницы **обязательно** проверить все ссылки на неё
со всех остальных страниц. Найти ссылки:

```bash
grep -rn "имя-страницы" --include=*.html --include=*.js .
```

Ключевые точки входа, которые нужно проверять после каждого деплоя:
- **index.html** (главная) — блоки-ссылки на страницы игр/продуктов.
- **catalog.html**, **dlya-sebya.html**, **avtorskaya-sistema.html** — ссылки в каталог/на лендинги.
- **assets/js/data.js** — карточки продуктов (`slug`, `img`), используются `product.html?slug=...`.
- Футер каждой страницы — ссылки на разделы и лендинги.

Правило: **не меняем URL, на который уже стоят ссылки.** Если нужен новый лендинг по
существующему адресу — кладём его в тот же файл (напр. `tochka-sily.html`), а не заводим
новый адрес и не правим ссылки по всему сайту.

После деплоя прокликать: главная → все ссылки на лендинги открываются, 404 нет.

## 2. ТРЁХЯЗЫЧНОСТЬ (RU / EN / DE) — на КАЖДОЙ странице

Сайт трёхязычный. Языки: **ru, en, de**. Движок — `assets/js/i18n.js` (словарь),
`assets/js/site.js` (переключатель `.lang` с кнопками RU/EN/DE + применение перевода),
выбор языка хранится в localStorage.

На каждой странице обязательно:
- [ ] Подключены `assets/js/i18n.js`, `assets/js/data.js`, `assets/js/site.js`.
- [ ] В шапке присутствует **переключатель языков RU / EN / DE** и он работает.
- [ ] Все видимые тексты вынесены в ключи `data-i18n="..."`.
- [ ] Для КАЖДОГО ключа есть перевод во ВСЕХ трёх языках в `i18n.js` (ru + en + de).
      Пустой перевод = пустой текст на странице, это баг.
- [ ] Переключение RU→EN→DE меняет весь текст, ничего не остаётся на другом языке.
- [ ] `<html lang="...">` и `<title>`/`meta description` тоже переключаются (или заданы нейтрально).

Проверка после деплоя: открыть страницу, переключить на EN и на DE — убедиться, что
не осталось русских (или пустых) кусков.

## 3. Технические проверки (каждый деплой)

- [ ] Нет битых ссылок и картинок (Network → нет 404).
- [ ] Изображения оптимизированы (WebP), крупные не грузятся там, где показываются мелко.
- [ ] Нет горизонтального скролла на мобильном (375px) и на десктопе.
- [ ] Favicon, `<title>`, `meta description`, Open Graph заданы.
- [ ] Формы: указано, куда уходят заявки (почта/Telegram/CRM), либо стоит рабочая заглушка.
- [ ] Проверить на: iPhone, Android, планшет, ноутбук, desktop ≥1920px.

- ⚠️ **Пока только на русском, без переключателя языков** — НЕ соответствует п.2.
- Целевой адрес — `/tochka-sily` (на него уже ссылаются index.html, dlya-sebya.html,

  лендинг его нужно сделать трёхязычным (RU/EN/DE + переключатель), иначе на этом URL
  пропадут EN и DE.
