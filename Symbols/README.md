# Символы древних цивилизаций

Самостоятельное статическое приложение для https://yuliastoyanova.com/Symbols/. Все пути относительные. Оно не использует общие стили, серверные обработчики, авторизацию или ключи других приложений сайта. Хостинг: существующий Cloudflare Workers Static Assets из корня stoyul/mysite.

## Материалы

132 символа: Лемурия 30, Гиперборея 30, Атлантида 30, Сириус 30, галактические системы 12 (Сатурн, Плеяды, Венера, Большая Медведица, Андромеда). 132 авторские карточки и 10 карточек правил. Бинарные файлы скопированы без изменений: контрольные суммы находятся в data/audit.json. Дубликатов карточек нет.

Карточки всех предоставленных коллекций имеют размер 340 × 200. Отдельных чистых изображений нет. 30 карточек Гипербореи сопоставлены по номерам с файлами 005–034, файлы 001–004 — правила. Просмотр для нанесения использует оригинал целиком, без обрезания и искусственного увеличения. Высокое разрешение невозможно восстановить из отсутствующего исходника.

Полный документ извлечён из DOCX в data/author-original.txt. Каждое fullDescription является точным отрезком этого текста, проверенным по исходным смещениям; сохраняются устная речь, опечатки и авторские утверждения. Структурированные выдержки не заменяют оригинал. Имена Гипербореи сверены по оригинальным карточкам; исходная расшифровка не изменена.

## Подбор

Локальная смысловая модель: TF-IDF полного корпуса, 48-мерное латентное семантическое пространство (LSA), фразовая интерпретация 74 направлений в 49 сферах и проверенная привязка намерений к авторским выдержкам. Учитываются все назначения одного символа, многотемный запрос и выбранная система. Редкие термины дополнительно ищутся по полному исходному тексту. Объяснения цитируют только источник. Результаты не ограничены числом 3, проходят порог релевантности и разделяются на основные и дополнительные.

Это локальная статистическая модель небольшого авторского корпуса, а не большая языковая модель или нейросетевые embeddings. Она распознаёт предусмотренные перефразировки и латентные связи, но не гарантирует понимание любой формулировки. Неизвестные запросы могут честно дать пустую выдачу. Пользователю не показываются проценты совпадения. Персональные запросы не передаются во внешний сервис.

## Состояние

Сохранения: localStorage['ys.symbols.saved.v1']; последний запрос: sessionStorage['ys.symbols.query.v1']. Сохранения доступны на том же устройстве, без автоматической синхронизации. Экспорт и объединяющий импорт JSON позволяют переносить коллекцию. Полный экран символа имеет адрес #library?symbol=id или #search?symbol=id. Возврат сохраняет запрос и позицию в списке. Service Worker не регистрируется.

## Производительность и доступность

Модель загружается только при подборе. Изображения используют lazy loading, decoding=async, фиксированные пропорции и исходные небольшие файлы. Подробные описания загружаются по одному. Имеются клавиатурные фокусы, настоящие dialog, закрытие Escape, подписанные поля, aria-live, reduced-motion и мобильные safe areas. Исходная библиотека содержит медицинские и эзотерические утверждения; интерфейс обозначает их как авторский материал и содержит мягкое предупреждение об ограничениях.

## Воспроизводимость

Вне опубликованной части, в tools/: build_data.py → structure.py → review.py → extend_topics.py → build_semantic.py. Последний требует numpy (доступен в bundled Python). verify.mjs проверяет дословность всех описаний, неизменность карточек, многотемность, отсутствие случайных результатов, фильтры, необычные назначения и происхождение объяснений. Запуск: node --test tools/verify.mjs. Обычный сервер: python3 -m http.server из родительского каталога.

Глобальные компоненты сайта не изменяются. На главной меняется только ссылка существующей карточки направления «Символы» на /Symbols/. Основной язык приложения русский, чтобы сохранить предоставленный авторский материал.

## Обновление намерений
Сценарии жизненных задач выделяют прямые связи (вес 1) и дополнительные процессы (вес .35); расширенный текст проецируется в LSA полного корпуса. Пользователь может удалить и добавить любое направление. Доказательства назначения — дословные отрывки авторского текста. Это прозрачная локальная модель с правилами, а не универсальное понимание любым AI.

Связи найдены в существующем сайте: put-k-sebe/config.js → https://t.me/IntentionCrystal7D_bot; consultation.html → запись; put-k-sebe/index.html → марафон. Старый /symbols/ переводит на /Symbols/ с сохранением hash и query. Ключи сохранения не изменены.
