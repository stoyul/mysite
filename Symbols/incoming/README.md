# Замена карточек

Положите новые исходники в cards/ с именами стабильных идентификаторов: lemuria-01.jpeg, atlantis-01.png, hyperborea-01.jpeg, sirius-01.jpeg, galactic-01.png и так далее. Полный список находится в data/symbols.json. Для произвольных имён используйте --mapping с JSON вида {"lemuria-01":"мой-файл.png"}.

При выполнении tools/build_semantic.py обработка incoming/cards запускается автоматически. Для замены только изображений можно отдельно запустить tools/prepare_images.py --incoming incoming/cards. Скрипты запускаются из папки Symbols или с абсолютными путями.

Обработчик сохраняет исходный файл с контрольной суммой и создаёт WebP без потерь шириной до 340, 680, 1020 и 1360 пикселей; увеличения сверх исходника нет. Пропорции, прозрачность и цветовой профиль сохраняются. Подбор версии выполняется браузером через srcset. Увеличенный просмотр использует оригинал. После обработки публикуйте images.json и созданные assets/originals и assets/web вместе с приложением.

Не помещайте в cards старые карточки правил. Для готовых небольших карточек обработчик уменьшает вес без снижения пиксельного размера.
