# Обновление приложения «Символы древних цивилизаций»

Адрес: https://yuliastoyanova.com/Symbols/

## Что изменено

- index.html: метаданные нового пути, диалог исправления направлений.
- style.css: основной текст 18px, кнопки 18px, подписи/теги 17px, адаптивный портал и три сценария входа.
- app.js: богатые подсказки, основные/дополнительные направления, ручное редактирование, бот, консультация, марафон, новые правила.

- data/index.json, symbols.json, intents.json, semantic.json, audit.json и details/hyperborea-*.json: обновлённая база и модель.

- tools/build_data.py, extend_topics.py, verify.mjs, intent-cases.mjs: воспроизводимость и проверки.
- Главная сайта: только ссылка на /Symbols/. Старый /symbols/ переводит на новый путь.

## Гиперборея

30 карточек сопоставлены по номерам: файл 005 — символ 1, файл 034 — символ 30. Файлы 001–004 — авторские правила. Названия сверены визуально; полный исходный текст сохранён без исправления расшифровки. Все 30 доступны в поиске, фильтре и библиотеке. SHA256 подтверждает неизменность всех 132 карточек.

## Смысловой слой

Запрос → распознавание жизненной задачи → прямые направления (1) и дополнительные процессы (.35) → сопоставление с доказанными назначениями → LSA по полным описаниям → порог релевантности и ранжирование. Словарь содержит 74 направления в 49 сферах. Пользователь может удалить и добавить направления; ручной выбор сохраняется при фильтрации цивилизации. Это локальная модель LSA с фразовыми правилами, не универсальная большая языковая модель. Неизвестные запросы могут давать пустую выдачу.
