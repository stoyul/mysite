## Найденные технические ошибки

- sumDay складывает длительности пересекающихся дел: двойной учет времени.
- save() проглатывает исключения: пользователь может думать, что данные сохранены.
- retry-event снимает флаг выбора без отката ресурсов: можно повторять награду.
- SIM не меняет последующие сценарии по прошлым решениям; меняются числа и текст истории.
- simReset стирает предыдущий год; нужен архив сессий.
- импорт JSON проверяет только наличие profile и массива tasks; требуется полная схема и предпросмотр.
- даты через toISOString смешиваются с локальным календарем.
- часть полей состояния не используется или не отображается; не удалять до проверки назначения.

Ни один исходный файл не удален и не перезаписан. Новый интерфейс пока не заменяет прототип по полноте.
