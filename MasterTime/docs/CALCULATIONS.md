# Реестр расчетов

Реализация: src/domain.mjs. Тесты: tests/domain.test.mjs. Все длительности — реальные минуты; игровые ресурсы отдельно.

| Расчет | Правило | Проверка |
|---|---|---|
| Начало задачи | Локальная дата + часы + IANA zone → UTC instant через проверенные кандидаты смещений | Europe/Berlin, America/New_York, переход года |
| Длительность | Целое 1–1440 минут; конец = начало + минуты × 60000 | Некорректные значения отклоняются |
| Двусмысленное время | Осенью требуется первое/второе вхождение; по умолчанию ошибка. Весной отсутствующее время отклоняется | 29.03.2026, 25.10.2026 02:30 |
| Пересечение | max(начал) < min(концов), границы [start,end) | Соседние дела не конфликтуют; вложенные учитываются всеми парами |
| Дневная занятость | Длительность объединения интервалов, обрезанных границами локального дня | 09–11 и 10–12 → 180 минут, не 240 |
| Дело через полночь | Учитывается часть на каждом дне | 23:30 на 90 мин → 30 и 60 |
| Длина суток | Между двумя локальными полуночами, не фиксированные 1440 | 1380 весной, 1500 осенью |
| Сон | Время в постели по заданным часам; ночной режим разбивается на две части выбранного календарного дня | 23:30–07:00 → 450 мин обычно, 390/510 при DST |
| Свободные интервалы | Дополнение объединения занятости до границ дня | Проверены интервалы и сумма |
| Свободное бодрствование | Дополнение объединения задач и сна; не вычитать пересечения дважды | Задача 06:30–07:30 при сне до 07:00 → свободно 960 мин |
| Категории | Объединение интервалов каждой категории отдельно | Сумма разных категорий может превышать общую занятость; это указано в UI |
| План дня и цели | Выполненные / запланированные × 100; округление до 2 знаков | 21/30 → 70; 0/0 → null («нет данных») |
| Привычки | Уникальные отметки в запланированные дни / запланированные дни периода | Пн/Ср/Пт в феврале: 12; посторонние и повторные отметки не засчитываются |
| Периоды | Гражданские даты через UTC календарную арифметику, отдельно от реальных моментов времени | Високосный февраль, конец года, неделя через декабрь/январь |
| Дело | +5 кристаллов впервые за ID | Снять/вернуть галочку не дает повторную награду |
| Карточка | +3 кристалла впервые за стабильный ID | Повторная практика хранится без повторной награды |
| День | +10 за завершение дня с выполненными делами; будущий день не закрывается | Ключ day:YYYY-MM-DD, идемпотентность общего журнала |
| Месяц | +30 однократно при создании главы завершенного месяца | Ключ month:YYYY-MM; текущий/будущий месяц не закрывается |
| Мастерство | 1 + floor(сумма наград / 100) | 100 кристаллов → уровень 2 |
| Глава | Неизменяемый глубокий снимок фактических данных; ключ YYYY-MM | Изменение целей после снимка не меняет главу; повтор не создает дубликат |

С 15.10.2026 ресурсы и зависимые сценарии первого игрового дня реализованы и проверены: docs/GAME_RULES.md. Еще не реализованы и не проверены: ресурсы полной недели/месяца/года, отпуска, Prime Time по наблюдениям, серверные награды и защита от подмены клиентом. Текущий локальный журнал можно изменить средствами браузера; он не является защищенной игровой экономикой.

Планируемые привычки интерфейса сейчас начинаются с первого дня выбранного месяца; ежедневная или Пн/Ср/Пт. Произвольная дата старта, окончания и выбор собственных дней — следующий этап. Будущие дни отмечать нельзя. Прогресс показывается за весь месяц, а не только за прошедшие дни; знаменатель подписан. Полный паспорт, дневник энергии и история режима сна еще нужны: текущий расчет использует одну выбранную настройку для всех дней и не претендует на фактическую историю сна.
