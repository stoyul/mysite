# Инструкции проекта «Мастер времени»

1. Экономь токены и контекст.
2. Не перечитывай весь репозиторий при каждой задаче.
3. Читай только файлы, необходимые для текущего этапа.
4. Не переписывай работающие компоненты без необходимости.
5. Используй точечные изменения.
6. Не повторяй длинное техническое задание в ответах.
7. Отвечай кратко: «Сделано», «Проверено», «Следующий шаг».
8. Проверяй измененные функции; перед публикацией проводи полное тестирование.
9. Не изменяй другие проекты на сайте. Все изменения приложения держи в MasterTime.
10. Сохраняй все игровые механики. HTML-прототип найден в MasterTime; сверяй перенос с docs/PROTOTYPE_PARITY.md и не утверждай, что он завершен без проверки.
11. Не используй букву «ё» в русских текстах интерфейса. Исходные материалы сохраняй дословно отдельно.
12. Используй крупный шрифт, премиальный черно-малиново-золотой дизайн и плавные анимации; поддерживай prefers-reduced-motion.
13. Обеспечивай полноценную работу на мобильных устройствах и в Telegram Mini Apps.
14. Не размещай секреты и токены в публичном коде. Код доступа проверяется только сервером. Роль Users не назначается по клиентскому вводу.
15. После каждого этапа обновляй PROJECT_STATUS.md: проверенные факты, ограничения, тесты и следующие действия.
16. Не выдавай незавершенную функцию за готовую. Локальное сохранение не заменяет серверную базу.

## Куда смотреть

- Требования: TECHNICAL_SPEC.md; состояние: PROJECT_STATUS.md.
- Источники и соответствие: docs/MATERIALS.md, docs/PROTOTYPE_PARITY.md.
- Архитектура и безопасность: docs/ARCHITECTURE.md.
- Расчеты: src/domain.mjs, docs/CALCULATIONS.md, tests/domain.test.mjs.
- Новые материалы: tools/import_materials.py. Обновляй каталог без дублирования карточек и без потери пользовательского прогресса.
- Проверка: bundled Node `--test tests/*.test.mjs`; интерфейс проверяй отдельно в браузере.
- Публикация в main сайта автоматически затрагивает боевой домен. Не отправляй туда незавершенную работу. Не меняй корневой wrangler.toml без отдельной проверки интеграции.

- Основной путь — игра (#game/#play), а планировщик и каталог — вспомогательные инструменты. Не возвращай боковое меню на игровой старт.
- Игровые правила и фазы: src/game.mjs, src/game-view.mjs, docs/GAME_RULES.md.
- После изменения интерфейсных модулей запускай tools/build.mjs: index.html использует производный assets/app.js для работы и через file://.
