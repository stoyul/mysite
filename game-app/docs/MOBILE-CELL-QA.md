# Проверка рисунков в клетках

Проверены SVG игрового поля, экспортированные из действующего `makeBoard`, при ширине 320 и 390 пикселей для всех пяти миров. Файлы проверки: `docs/qa/world-N-320.png` и `docs/qa/world-N-390.png`. Это проверка реальной геометрии секторов и подключенных изображений, без увеличения символов. Это не проверка браузера или физического телефона: совместимый браузерный предпросмотр для текущего Worker-проекта недоступен.

У всех 104 клеток сохранены ID, порядок маршрута и геометрия. Иллюстрации остаются внутри маски сектора, обводка расположена поверх изображения. Основной символ занимает около 60–65% ширины среднего сектора.

| Символы | Результат при 320 и 390 px |
|---|---|
| Портал / Океан иллюзий | Полое бирюзовое кольцо отличается от заполненной фиолетовой воронки |
| Диагностика / Хранитель / Архетип | Различаются силуэтом, позой и цветом |
| Потребность / Тень / Энергия / Ключ | Сердце, двойной кристалл, импульс и ключ читаются отдельно |
| Озарение / Другой взгляд / Событие | Профиль со звездой, глаз и кубик имеют разные силуэты |
| Возвращение / Творение / Цель / Действие / Поддержка | Вихрь к сфере, формирующие руки, луч к звезде, шаг и открытые руки различимы |

Резервный символ утечки не добавлен на маршрут. У него проверены прозрачность и единый стиль.

Автоматически проверены фазы редких анимаций, неподвижность маски, сохранение маршрутов и отключение движения при `prefers-reduced-motion`. В статических PNG анимации не воспроизводятся.
