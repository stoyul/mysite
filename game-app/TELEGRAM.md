# Telegram Mini App — Точка силы

URL приложения: **https://yuliastoyanova.com/play/**.
Это та же игра и тот же GitHub → Cloudflare деплой. Все будущие изменения
в `game-app/dist` публикуются в `play` командой `node game-app/scripts/sync-public.mjs`.

## Подключить своего бота

1. Открыть проверенного `@BotFather` в Telegram. Создать бота через `/newbot`, если его еще нет.
2. `/mybots` → свой бот → Bot Settings → Configure Mini App → Enable Mini App.
   Указать URL приложения выше и добавить название, описание и обложку.
3. `/setmenubutton` → свой бот → URL выше → подпись `Открыть игру`.
4. После включения Main Mini App ссылка запуска: `https://t.me/ИМЯ_БОТА?startapp`.
   Простая ссылка на сайт в сообщении открывает браузер, поэтому использовать кнопку бота
   или ссылку запуска Main Mini App.

Названия пунктов BotFather могут зависеть от языка клиента.
Токен бота не нужен фронтенду. Не добавлять его в GitHub, JavaScript или переписку.

## Поведение и ограничения

- Официальный Telegram SDK, `ready`/`expand`, фирменные цвета окна.
- Отступы для системных элементов и обновление высоты при изменении окна.
- В Telegram 8.0+ есть кнопка включения/выключения полного экрана.
- Старые клиенты работают в развернутом окне, без полноэкранного API.
- Обычный сайт продолжает работать, в том числе при недоступном SDK.
- Запрос, ответы, ключи, энергия и решения по кругам сохраняются существующей
  игровой системой локально в браузере этого устройства. Прогресс сайта и
  Telegram, а также разных устройств не синхронизируется автоматически.
- Telegram-профиль не считается авторизацией. `initDataUnsafe` не используется.
  При добавлении серверных профилей необходима серверная проверка `initData`.
- Ответы не отправляются боту или в Telegram CloudStorage.
- Звук по-прежнему включается только после действия пользователя.

Проверка адаптера: `node game-app/tests/telegram-miniapp.mjs`.
После подключения бота дополнительно проверить реальные iOS/Android клиенты:
вступление, полный экран, прокрутку карты, клавиатуру, звук и продолжение после закрытия.
