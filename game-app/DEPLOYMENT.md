# Точка силы на yuliastoyanova.com

Рабочий проверенный адрес игры: https://stoyul.github.io/mysite/play/\n\nЦелевой адрес основного домена: https://yuliastoyanova.com/play/ — пока возвращает 404. Workers Builds завершались ошибкой еще на исходном коммите 4f9154e6a2cab5a9a3a76ab7e8519a2ce3aba008. Подробный лог доступен в аккаунте Cloudflare; повторная публикация не исправляет неизвестную причину ошибки. До ее устранения кнопка онлайн-игры ведет на рабочее зеркало. После успешной публикации на домене замените ее ссылку на ./play/.

Полная версия исходников: `game-app/`. Опубликованная браузерная сборка: `play/`. Существующий `wrangler.toml` основного сайта сохранен. `.assetsignore` исключает исходники игры из публичной раздачи.

После изменения интерфейса или данных в `game-app/dist` копируйте содержимое в `play` (без `client`, `server`, `.openai`). Например: `node game-app/scripts/sync-public.mjs`. После push в main используется существующая публикация основного сайта.

Прогресс текущего прохождения сохраняется в браузере на новом домене. Данные со старого домена автоматически не переносятся. Журнал старого прохождения можно скачать в прежней игре.

Облачные профили ранее были выключены и остаются выключенными. Standalone Worker не доверяет заголовку oai-authenticated-user-id. Для включения профилей нужны проверяемые сервером сессии, контакт в политике, база D1 с миграциями и отдельная публикация Worker. Не включайте privacy.ready только ради обхода этого ограничения.

Для отдельного Worker: создать D1, заменить ID в wrangler.jsonc, выполнить миграции `npx wrangler d1 migrations apply DB --remote --config wrangler.jsonc`, собрать `npm run build`, затем `npx wrangler deploy --config wrangler.jsonc`. Авторизацию реализовать до включения cloudProfiles. Поддомен game.yuliastoyanova.com подключается в Cloudflare отдельно.

Дальнейшие изменения игры необходимо выполнять в этом репозитории. Исходная Sites-публикация не синхронизируется автоматически.
